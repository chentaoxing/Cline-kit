Cline-kit 0.1.0 - first public release. Windows only.

**What it does.** Cline's sidebar project groups only list folders that already have sessions, so every
project you registered but have not opened is simply absent. Cline-kit keeps all of them listed with
native styling and lets you switch into an empty project from the sidebar. It is a runtime overlay
injected over Cline's own WebView2 debugging channel: `cline-app.exe` is not patched, its signature and
auto-update stay as shipped, and `ckit uninstall` restores your shortcuts exactly.

**Also included:** UI locale packs - zh-CN (reference), zh-TW, ja, ko, vi, 476 strings each.
`ckit config --dictionary=ja` changes the open window immediately, no reload.

**Install**

- `npm install -g cline-kit` (package publication pending; until then use the next two routes)
- download `cline-kit-v0.1.0-win.zip`, unzip, run `ckit.cmd install` then `ckit.cmd start`
- or `git clone https://github.com/chentaoxing/Cline-kit.git` and `npm install -g .`

Requires Windows 10/11, Node.js 20.10+, and the Cline desktop app (verified against v0.0.32).

**Verified before tagging:** `npm test` (24 checks) green; `ckit doctor` green against the running app
(15 rows added of 19 registered workspaces, 3 native groups, idle DOM write rate 0); every locale
rendered in the live window via `node scripts/locale-switch-check.js`; the zip extracted and its
`ckit.cmd` run from the extracted copy.

**Honest limits.** Windows only. Locale dictionaries other than zh-CN are complete but machine-assisted
and not reviewed by native speakers. Model/provider/product names are never translated. Selectors are
Cline's internal class names, so a Cline redesign can need a fix - `ckit doctor` tells you.
